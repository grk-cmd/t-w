# 메인 페이지 프로토타입 (together-working.com)

메인 홈페이지를 어떻게 꾸밀지 **레이아웃을 보는 용도**의 프로토타입이다. 배포하지 않는다(Hosting 에 올라가지 않음).
실제 페이지를 만들 때 자리 · 흐름 · 문구의 기준으로 삼고, 코드는 그대로 옮기지 않는다.

## 여는 법
`index.html` 을 브라우저로 연다(저장소를 받은 그대로 — 그림은 `app/assets/icon/` · `build/icon.iconset/` 을 상대 경로로 읽는다).
제목 글꼴(갈무리 · DotGothic16)은 CDN 에서 받으므로 인터넷이 없으면 맑은 고딕으로 보인다.

## 진짜가 아닌 것 — 만들 때 따로 정한다
- **미리보기는 2D 그림**이다. 실제로는 고른 레이어를 512×512 얼굴 텍스처(앱 그림판 크기)로 합쳐 3D 머리에 입힌다.
- **파츠 그림**(눈 5 · 눈썹 4 · 입 5 · 볼 4 · 머리 5)은 레이어 구조를 보이려고 대강 그린 것이다.
- **앱으로 가져가기 코드 · 로그인 · 라이브러리 올리기**는 화면만 있다. 라이브러리는 서버(자체 서버)에 만든다 — 익명이어도 신고가 오면 운영진은 올린 계정을 볼 수 있어야 한다.
- **다운로드 비밀번호**는 확인하지 않는다(이 저장소는 공개라 비밀번호 · 해시를 두지 않는다). 실제로는 서버가 확인한 뒤 내려받기 주소를 준다.
- **소식 · 운영진 · 라이브러리 이름 · 숫자**는 예시다. 소식 글은 번역하지 않는다(공지 번역 방식은 운영진이 정하는 중).
- **번역**은 화면 글자를 사전(`main.js` 의 `I18N_DICT`)으로 바꾸는 시안용 방식이다. 실제로는 언어별 파일로 모으고 원어민 검수를 받는다.

## 디자인 기준
- 앱 «클래식» 테마(Win98) 한 벌 — 회색 입체 창 · 남색 타이틀바 · 청록 바탕화면(`docs/design-system/project/tokens.json` 의 classic 값).
- 제목 글꼴은 갈무리11 굵게(SIL OFL 1.1) — 11칸 픽셀 격자라 22 · 33px 에서 또렷하다. 본문은 Tahoma · 맑은 고딕.
- 운영진 말풍선 · 장면 말풍선은 앱 머리 위 도트 말풍선(`app/desk-companion-prototype.html` 의 `.seat-bubble-dom`)과 같은 아트 · 수치.
