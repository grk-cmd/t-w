## 0.12.3 업데이트

- 꾸미기 › 책상과 캐릭터 만들기 5단계에 «🚫 책상 없음» 이 생겼어요 — 책상만 사라지고 책상 위 아이템은 그대로예요 · 책상 없는 캐릭터는 몸 크기만큼만 자리를 차지해 옆 캐릭터와 가깝게 앉아요(«모양이 안 보이는 책상» 대신 써 주세요)
- 설정 › 캐릭터 «좌석 간격» 을 더 좁힐 수 있어요 — 맨 왼쪽 칸에서는 책상끼리 살짝 겹쳐 붙어요(맞춰 둔 간격은 그대로 · 막대에서는 한두 칸 오른쪽에 보일 수 있어요)
- 책상을 끌어 자리를 바꾸면 놓은 곳에서 가장 가까운 자리로 가요 — 조금만 끌어도 여러 칸 건너뛰던 일이 줄었어요
- 💣 폭탄으로 날리거나 캐릭터를 끌어 옮길 때 방의 모든 캐릭터가 작아지던 문제를 고쳤어요(끄는 동안 화면이 줄어 다른 캐릭터 머리 위에 올리기 어렵던 문제도 함께)
- 투게더룸에서 내가 보낸 채팅만 대화창에 남지 않던 문제, 방 만들기 카드를 빠르게 두 번 누르면 방이 두 개 만들어지던 문제를 고쳤어요
- 런처에서 연 마이홈에서 «말랑이 숨기기» 가 눌리지 않던 문제를 고쳤어요
- 맥에서 투게더워킹이 켜져 있으면 앱스토어 · 암호 확인 창의 입력 칸이 비어 보이던 문제를 고쳤어요
