## 0.12.2 업데이트

- 플레이리스트 프리셋마다 🔒 «나만 보기» 를 걸 수 있어요 — 잠근 프리셋은 파도타기에 안 뜨고 나만 들어요
- 버그 제보에 [건의] 분류가 생기고, 내 제보를 공개 ↔ 비공개로 바꿀 수 있어요(운영자 답변이나 내 답글이 달리기 전까지) · 관리자가 «검토중» 으로 표시해요
- 기념일을 목록형으로도 볼 수 있어요(▦ ☰ 단추) · 선물함에서 우클릭으로 받은 그림을 내 컴퓨터에 저장해요
- 워킹룸에서 받은 이모티콘 소리를 들을 수 있어요(처음엔 꺼짐 · 이모티콘 창 🔔/🔕 단추)
- 투게더워킹 창을 쓰는 동안에는 캐릭터가 잠들지 않아요(손을 뗀 지 8초가 지나면 잠들어요) · 피규어 모드에서는 입력이 끊겨도 잠들지 않아요(포커스 · 달성표 시간은 쌓이지 않아요)
- 앱을 켜면 마지막에 런처를 둔 자리에서 떠요 · 방에서 책상이 없거나 작은 좌석도 옆 책상과 겹치지 않게 간격을 잡아요
- 버그 제보 글 · 답변 · 답글 속 주소를 누르면 기본 브라우저로 열려요
- 도움말 웹 페이지에 검색 · FAQ 가 생기고, 도움말에 «라이선스로 쓸 수 있는 것» 편이 생겼어요
- [내 정보] 의 전체 랭킹을 없앴어요
- 맥에서 플레이리스트 소리가 안 나던 문제, 맥에서 마우스를 올리면 뜨는 설명이 앱 창 뒤로 숨던 문제를 고쳤어요
- 펜 앱(클립스튜디오 등)에서 펜 입력이 씹히던 문제, 주모니터를 바꾸면 엉뚱한 모니터로 가던 문제를 고쳤어요
- 설정창 위쪽이 화면 밖으로 잘리던 문제, 스티커사진방에서 동물 캐릭터가 크게 서던 문제를 고쳤어요
