## 0.13.1 업데이트

- 대화창 입력칸 옆에 [보내기] 버튼이 생겼어요 — Enter 와 똑같이 보내요
- 방 안에서 여는 방 목록 창이 좁아지고 맨 아래에 [닫기] 버튼이 생겼어요
- 최근 들어간 방에 시크릿룸 코드가 그대로 남지 않아요 — «SCRT-****» 로 보이고, 누르면 코드 4자리를 물어요
- «같이 듣기» 를 잠시 꺼 두었어요 — 방 만들기 · 시크릿룸 설정에서 보이지 않아요
- 마이홈 스티커에 예전에 적어 둔 글은 그대로 남아 마우스를 올리면 보여요 · 새로 넣는 링크는 http:// · https:// 주소만 받아요
