## 0.12.0 업데이트

- 정식 도메인(together-working.com)이 생겨 접속이 더 빠르고 안정적이에요
- 방에 들어가도 친구가 보이지 않던 문제가 개선됐어요
- 마이홈에 «도움말» 탭이 생겼어요 (도움말 · 개인정보 처리방침은 help.together-working.com 에서도 볼 수 있어요)
- «우편함»이 «알림함»으로 바뀌었어요
- 가챠로 뽑은 파츠가 모든 기기에 안전하게 저장돼요 (로그인 · 인터넷 연결 상태에서만 뽑을 수 있어요)
- 실행 화면 화질을 고를 수 있어요 (설정 › 모니터)
- 스티커사진 음악 끄기 · 말랑이 숨기기 · 회원 탈퇴가 생겼어요
- 앱 크기가 줄고, 보안 업데이트가 적용됐어요
- 친구 목록 · 채팅 · 로그아웃 · 플레이리스트 · 캐릭터 표시 관련 오류를 고쳤어요
