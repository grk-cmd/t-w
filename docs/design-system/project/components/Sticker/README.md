하두리 장식 — 스티커 사진 틀 · 점무늬 · 반짝이(✦✧) · 도트 글자. 꾸미는 공간에서만 쓴다.

- `.tw-sticker`: 바탕 `sticker-peach` + `sticker-pink` 점무늬(8px 간격), 안쪽 `sticker-mint` 점선. 사진 칸은 `bg-field`, 모서리 0.
- 문구 `sticker` 스타일(`pixel` 서체 16px). 날짜·하트·물결(♡ ~ ☆) 같은 그 시절 기호를 써도 된다.
- 반짝이 `.tw-spark` 는 2~3개까지, 움직이지 않는다(움직임은 사진 찍는 순간 한 번만).
- **쓰는 곳**: 마이홈(미니홈피), 스티커 사진(푸리쿠라), 꾸미기 결과, 뽑기 결과 카드.
- **안 쓰는 곳**: 설정·확인창·버그 게시판·상태칩·이름표 — 일을 방해하는 자리.

**앱 대응**: 마이홈 테마(`_mhApplyTheme`, `--gb-*`)·푸리쿠라(`purikura-net.js`) 틀이 이 토큰을 받게 한다.
