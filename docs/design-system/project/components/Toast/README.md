잠깐 떴다 사라지는 한 줄 알림 — 윈도 툴팁 노랑 «쪽지».

- `tooltip-bg` + `tooltip-ink` 1px 테두리 + `shadow-toast`(각진 그림자). 모서리 0 — 세 테마 모두 같다. 쪽지 감성의 핵심이라 둥글리지 않는다.
- 화면 아래 가운데, 아래에서 18px 올라오며 나타남(.25s). 기본 1.9초, 되돌리기 버튼이 있으면 4초.
- 한 줄 · 25자 안팎. «~했어요» 로 끝낸다. 앞 이모지는 **결과의 주인공**이 사물일 때만 하나(🪑 벤치에 앉았어요). 실패 문장엔 이모지를 붙이지 않는다.
- 오류라도 빨간 토스트를 따로 만들지 않는다 — 문장으로 말하고, 고칠 길이 있으면 창 안 `tw-err` 로.
- 마우스 통과(`pointer-events:none`). 되돌리기 버튼을 넣을 때만 그 버튼에 히트 영역을 준다.

**앱 대응**: `.toast` · `toast(msg, iconSrc, ms)` — 값 그대로, 토큰 이름만 바꾼다.
