창 크기를 바꾸는 손잡이 — 창 가장자리 가운데의 짧은 알약 + ⋮.

- `.tw-grip` 10×28(`size-grip`), 세로 가장자리용. 가로 가장자리용은 `.h`(28×10, ⋮ 를 90° 돌림).
- `bg-face` + 광택 + `line-strong` 테두리, 글리프 `ink-soft` 11px. hover 시 `ink-accent`.
- 모서리 대각선 손잡이(◢)는 쓰지 않는다 — 투명 오버레이 위에선 창 모서리와 바탕이 구분되지 않아 못 찾는다.
- 히트 영역은 보이는 알약보다 사방 4px 넓게(`::before` 로). 커서 `ew-resize` / `ns-resize`.

**앱 대응**: 창마다 다른 리사이즈 자리(오른쪽 아래 모서리, 숨은 가장자리)를 이 하나로 맞춘다.
