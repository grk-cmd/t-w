- `[💬 채팅 | ● ▾]` 가로 한 덩이. 왼쪽은 방마다 하나만 — 투게더룸 «💬 채팅» · 워킹룸 «😊 이모티콘» · 혼자면 없음(▾ 만). 높이 26, 이웃끼리 테두리 겹침, 덩이 바깥 모서리만 둥글다.
- ▾ 칸 = 지금 상태 점(9px + 1px 검은 테두리) + ▾. 누르면 두 칸 메뉴: 왼쪽 «내 상태»(점 + 이름 · 맨 아래 «« 런처로») · 오른쪽 «바로가기»(일정 알림 · 플레이리스트 · 설정 F1 · 꾸미기 F2 · 이동 F3 · 마이홈 F4 · 포커스 기록 · 춤추기 · 러시안룰렛). 칸 머리는 작은 회색 글자(10px).
- 새 소식은 ▾ 오른쪽 위 점 하나(숫자 없음 — 작업 중 숫자는 신경을 긁는다). 숫자는 메뉴 안 그 줄 끝에만.
- 아이콘은 이모지/글리프 한 글자 — 이 자리만 예외로 이모지를 허용한다(작아도 알아보는 모양이 필요).
- 모든 칸에 `title`. 회사원 모드로 화면을 숨겨도 ▾ 하나는 남는다(우클릭이 되돌리는 길).
