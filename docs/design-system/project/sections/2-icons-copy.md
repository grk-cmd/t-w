# 아이콘 · 글

## 이모지냐 SVG냐

| 자리 | 쓰는 것 | 이유 |
|---|---|---|
| 버튼 · 탭 · 세그먼트 · 메뉴 항목 | **SVG 선 아이콘** 14px, 선 1.6, `currentColor` | 테마 색을 따르고, 운영체제마다 모양이 안 바뀐다 |
| 상태칩 칸(💬 🔔 ♪ ▾) | 이모지 · 글리프 한 글자 13px | 28×26 안에서 알아보는 모양이 필요. 이 자리만 예외 |
| 토스트 첫 글자 | 이모지 0~1개 | 결과의 주인공이 사물일 때만(🪑 벤치에 앉았어요). 실패 · 오류엔 없음 |
| 마이홈 · 스티커 · 뽑기 결과 | 이모지 · 그 시절 기호(♡ ☆ ✦ ~) 자유 | 꾸미는 공간이라 하두리 감성의 주 무대 |
| 확인창 · 설정 · 버그 게시판 · 웹 관리자 | 이모지 없음 | 또렷함이 먼저 |
| 코드 주석 · 커밋 | 이모지 꼬리표 없음 | 저장소 규칙(CLAUDE.md) |

- 유료 표시 👑, 비공개 🔒, 고정 📌 처럼 **뜻이 정해진 기호**는 글자 앞 한 개까지 허용한다(낱말과 같이).
- 앱 마크는 도트 아이콘 하나뿐. 다른 로고를 만들지 않는다.

## 말투

- **앱(사용자에게)**: 짧은 해요체. «주소를 복사했어요», «방에 있을 때 쓸 수 있어요». 반말 · 하십시오체 · 느낌표 남발 금지.
- **버튼**: 동사 원형(«지우기», «방에 들어가기»). «확인/취소» 쌍 대신 할 일을 적는다.
- **확인창 제목**: «~할까요?» 질문 하나. 설명은 결과만 한 줄(«지워도 상대에게 알림은 가지 않아요»).
- **오류**: 무엇이 안 됐는지 + 할 수 있는 일. «열지 못했어요 — 주소를 다시 확인해 주세요». «오류 발생», 오류 코드만 쓰기 금지.
- **설정 이름 · 탭 · 표 머리 · 웹 관리자**: 명사형(«집중 시간 알림», «방 입장 최소 버전»). 웹 관리자는 문장도 명사로 끝낸다(«저장됨», «권한 없음»).
- 숫자 · 단위는 붙여 쓴다(42분, 3번째). 시각은 «방금 · 5분 전 · 10.08».
- 영어 낱말은 우리말이 있으면 우리말로(«프리셋» 처럼 이미 익은 것은 둔다). 개발 낱말(«렌더러», «노드», «동기화 실패») 금지.

| 🐾 동물 모습을 준비하는 중이에요 — 잠시 뒤 다시 올려주세요 | 아직 준비 중이에요. 잠시 뒤 다시 올려 주세요 |
| 이 친구를 목록에서 삭제할까요? (confirm) | 확인창: «이 친구를 목록에서 지울까요?» · [취소] [지우기] |
