# 오버레이 원칙

앱은 화면 전체를 덮는 **투명 · 항상 위** 창이다. 우리 UI 위가 아니면 클릭이 뒤의 사용자 앱으로 빠진다(click-through). 사용자는 이 위에서 하루 종일 그림을 그리고 일한다.

## 1. 작게 · 가장자리에

- 늘 보이는 조작부는 상태칩 묶음(`StatusChip`) **하나**. 새 기능은 여기에 칸을 늘리기보다 «더보기 ▾» 안으로 넣는다.
- 창은 열 때만 뜨고, 위치를 기억하며, 화면 가운데를 오래 차지하지 않는다.
- 이름표 글자는 `nameplate` 15px 기본 — 더 키우는 건 사용자 설정으로만.

## 2. 어떤 바탕에서도 읽히게

- 오버레이 글자 = `plate-ink` + `plate-outline` 8방향 외곽선. 흰 문서 · 검은 코드 편집기 · 사진 위 모두 통과해야 한다(`Nameplate` 미리보기의 세 바탕).
- 오버레이 버튼은 불투명 `bg-face` 면 + 테두리 — 반투명 유리 버튼 금지(바탕이 비쳐 글자가 묻힌다).
- 새 소식 점(`pop`)엔 1px 어두운 외곽을 둘러 흰 바탕에서도 보이게 한다.

## 3. 누를 자리는 분명하게 · 나머지는 통과

- 누르는 것은 `size-hit` 24px 이상. 히트 영역은 `UI_HIT_SEL` 화이트리스트에 넣는다 — 안 넣으면 눌러도 클릭이 뒤로 뚫린다(audit 검사 2).
- 장식(반짝이 · 후광 · 그림자 · 말풍선 꼬리)은 `pointer-events:none`.
- 확인창의 어두운 막은 그 창 영역 안에만. 화면 전체를 막으면 사용자의 작업 앱이 멈춘 것처럼 느껴진다.

## 4. 움직이지 않기

- 오버레이 요소는 상시 애니메이션이 없다. 예외는 해금 보상(회차 별 · 레벨 등급 배지)이며 `prefers-reduced-motion` 에서 멈춘다.
- 알림은 소리 · 흔들기 대신 점 하나. 숫자 배지는 창 안에서만.
- 토스트는 1.9초 · 한 번에 하나 · 마우스 통과.

## 5. 가볍게

- 전체 화면 위 `backdrop-filter` · 큰 블러 그림자 · 전체 덮는 그라데이션 금지. 그림자는 한 겹, 블러 18px 이하.
- 3D 캔버스는 프레임 상한 60 · 손 안 대면 30 으로 돈다 — UI 가 그 예산을 쓰지 않게, 오버레이 DOM 은 `transform` · `opacity` 로만 움직인다.

## 6. 숨길 수 있게 · 되돌릴 수 있게

- «사무실 숨기기» 중에도 상태 칸 하나는 남는다 — 되돌릴 길이 사라지면 안 된다.
- 창 위치 초기화(`resetAllWinPositions`)는 설정에 늘 둔다. 화면 밖으로 나간 창을 되찾는 유일한 길이다.
