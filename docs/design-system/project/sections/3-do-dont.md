# 해요 · 하지 마요

| 해요 | 하지 마요 |
|---|---|
| 창마다 기본 버튼은 하나, 타이틀바와 같은 그라데이션 | 한 창에 색 버튼 서너 개 |
| 타이틀바는 `.tw-titlebar` 한 규칙 | 인라인 `style="background:linear-gradient(90deg,var(--win-title-a)…"` 를 창마다 복사(HTML · app.js 에 49곳) |
| 글꼴은 `var(--font-ui)` | `font-family:Tahoma,'Malgun Gothic',sans-serif` 직접 적기(지금 121곳 — 버블 테마의 돋움이 안 먹는다) |
| 크기는 10 · 11 · 12 · 14 · 18 | 10.5 · 11.5 · 9.5 · 8 · 7px(지금 230곳 이상) |
| 회색은 `ink-soft` · `line` · `line-strong` 셋 | `#999` `#888` `#aaa` `#666` `#555` `#bbb` 같은 손 회색(HTML · app.js 에 130곳 이상) |
| 되돌릴 수 없는 일은 `ConfirmDialog` | `confirm()` · `alert()`(Electron 투명 창에서 멈춤 — app.js 에 아직 17곳) |
| 상태는 색 + 낱말(● 새 제보) | 빨강/초록 점만으로 구분 |
| 붓 · 채우기 · 지우개를 한 세그먼트로 | 지우개 켬끔 + 채우기 켬끔이 따로 있어 둘 다 켜지는 상태 |
| 크기 조절은 가장자리 가운데 알약 ⋮ | 투명 바탕 위 모서리 ◢ — 어디가 창 끝인지 안 보인다 |
| 하두리 장식은 마이홈 · 스티커에서 | 설정창 · 확인창에 반짝이 · 점무늬 |
| 토스트는 쪽지 노랑 + 각진 그림자 그대로 | 둥글고 흐린 «요즘 토스트» 로 바꾸기 — 정체성을 잃는다 |
| 이름표는 흰 글자 + 검은 외곽선 | 테마 색 이름표(밝은 바탕에서 사라진다) |
| 오버레이 버튼은 불투명 면 | 반투명 유리 · `backdrop-filter` |
| 테마 블록은 «모양만» 바꾸기(값은 기본 규칙 한 곳) | 테마 블록에서 여백까지 다시 정하기(기본 테마에서 여백이 사라진 사고) |
| 새 창은 컴포넌트 클래스로 — 테마가 자동으로 닿는다 | 새 창 ID 를 버블 테마 목록 여러 곳에 손으로 추가(빠뜨리면 그 창만 각진다) |
