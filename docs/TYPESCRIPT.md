# 앱 TypeScript 방향

앱(Electron 렌더러 · 메인)은 **TypeScript 로 간다. React 는 쓰지 않는다.** 한 번에 바꾸지 않고 단계로 간다.
지금 짜는 코드도 이 방향을 따르도록 아래 «지금부터 지킬 것» 을 지킨다.

## 왜 TS 인가
- 렌더러만 4만 줄이 넘고 모듈이 수십 개다. 없는 이름 부르기 · `deps` 빠뜨리기 · `typeof 이름` 가드로 «조용히 꺼짐»(10-15 이모티콘 변환 · 하트비트 경험치)은 사람 눈이나 화면 눌러 보기로 못 잡는다.
- 여럿(다른 세션 · 기여자)이 같이 고친다. 함수가 무엇을 받고 돌려주는지가 코드에 적혀 있어야 한다.
- 서버(t-w-server)로 옮기는 중이다. 범용 데이터 통로의 요청 · 응답 모양, 에러 코드 표가 타입이면 서버 규격과 어긋날 때 바로 드러난다.
- 이미 `sim-global-names` · `sim-dep-cycles` 가 typescript 파서를 빌려 같은 일을 손으로 하고 있다.
- 웹 관리자는 이미 TS(strict)다 — 언어를 하나로 맞춘다.

## 왜 React 는 아닌가
- 앱 화면은 three.js 3D 장면과 떠 있는 작은 창 · 팝업이다. «데이터가 바뀌면 목록을 다시 그리기» 가 중심이 아니다.
- 들이려면 번들러 · JSX 빌드에 화면 코드를 거의 다시 써야 하고, 모듈 떼어 내기 · 화면 검사도 다시 맞춰야 한다. 얻는 것(UI 짜기 편함)에 비해 비용이 크다.
- 목록 · 폼 중심 화면은 웹 관리자(React)에 둔다. 앱에 그런 화면이 크게 새로 생기면 그때 그 부분만 다시 따진다.

## 단계 (0.11.4 뒤 시작)
1. **빌드는 그대로, 검사만** — `.js` 는 그대로 두고 CI 에 `tsc --noEmit --allowJs --checkJs` 를 더한다. 선언 파일 하나(`app/types/globals.d.ts`)에 `window.TwXxx` · `window.companion`(preload) · 공용 전역을 적는다.
2. **파일마다 켜기** — 새 모듈 · 떼어 낸 모듈부터 맨 위에 `// @ts-check`. `createXxx(deps)` 의 `deps` 모양은 JSDoc 으로. app.js 는 마지막.
3. **손 검사 걷기** — tsc 가 대신하는 만큼 `sim-global-names` · `sim-typeof-guards` 같은 이름 검사를 줄인다(걷기 전에 같은 고장을 tsc 가 빨강으로 잡는지 일부러 깨 보고 확인).
4. **`.ts` 파일과 빌드** — 서버 API 타입을 같이 쓰는 등 필요가 생기면 빌드 단계(esbuild 또는 tsc)를 넣고 `.ts` 로 바꾼다. 1~3 을 해 두면 이름 바꾸기에 가깝다. 이때 CSP · Electron 패키징 · 원본을 읽는 검사들의 경로를 같이 본다.

## 지금부터 지킬 것 (TS 로 옮기기 쉬운 코드)
- **모듈 입구에 `deps` 모양을 적는다** — `createXxx(deps)` 위에 JSDoc `@param {{ 이름: 타입, … }} deps`. 읽는 함수로 넘긴 값은 `() => 값` 으로 적는다(값처럼 `typeof` 로 보지 않게).
- **전역은 정해진 이름으로만** — 새 전역은 `window.TwXxx` 모듈 이름 하나로. 문자열로 만든 이름(`window['_' + name]`)으로 읽고 쓰지 않는다 — 타입이 따라갈 수 없다.
- **`typeof 이름 === 'function'` 가드로 «없으면 조용히 넘어가기» 를 새로 만들지 않는다** — 있어야 하는 것은 `deps` 로 받고, 정말 없을 수 있는 것은 이유를 주석으로.
- **한 변수에 한 모양** — 숫자였다 문자열이었다, 배열이었다 객체였다 하는 값을 만들지 않는다. 서버에서 온 값은 받는 자리에서 한 번 모양을 맞춘다(마이홈 `myhome-state.js` 처럼).
- **null 은 일부러** — «아직 없음» 은 `null` 하나로, `undefined` · 빈 문자열 · `0` 을 섞어 뜻하지 않는다.
- **데이터 모양은 한 곳에** — 서버 · 방에 오가는 객체(좌석 def · 마이홈 · 통로 요청)는 만드는 함수 한 곳에서 만든다. 나중에 그 자리에 타입을 단다.
- **에러는 코드로** — 실패는 `docs/ERROR_CODES.md` 의 코드로. 문자열 비교로 갈래를 나누지 않는다.

## 안 하는 것
- 0.11.4 기능 멈춤 중에는 TS 작업(단계 1~4)을 시작하지 않는다. «지금부터 지킬 것» 만 새 코드에 적용한다.
- 지나가며 남의 파일을 통째로 TS 스타일로 고치지 않는다 — 모듈 떼어 내기와 부딪힌다. 고칠 일이 있는 파일에서만.
