1받기

기본 앱 단축어를 써요. 지웠다면 App Store 에서 «단축어» 를 다시 받아요.

Play 스토어에서 MacroDroid 를 받아요(무료로 충분해요).

2자동화 만들기

그림 앱 이름을 적으면 아래 복사 버튼에 들어가요. PC 에 이 이름이 보여요.

  1. 단축어 › 자동화 › ＋ › 앱 → 그림 앱 고르기 → «열릴 때»만 체크 → 즉시 실행
  2. 새로운 빈 자동화 → 동작 «텍스트» 추가 → [열림 본문 복사] 한 것을 붙여넣기
  3. 동작 «URL 콘텐츠 가져오기» 추가 → URL 에 [주소 복사] 한 것 · 방법 PUT · 요청 본문 파일 → 위 «텍스트»
  4. 같은 방법으로 «닫힐 때» 자동화를 하나 더 — 이번엔 [닫힘 본문 복사]

앱마다 «열릴 때 · 닫힐 때» 두 개씩 만들어요. 앱 이름을 바꾸면 복사 내용도 바뀌어요.

  1. 매크로 추가 › 트리거 › 애플리케이션 › 앱 실행/종료 → 실행됨 → 그림 앱 고르기
  2. 액션 › 연결 › HTTP 요청 → 방법 PUT · URL 에 [주소 복사] 한 것
  3. 콘텐츠 유형 application/json · 본문에 [열림 본문 복사] 한 것
  4. 매크로를 하나 더 — 트리거 종료됨 · 본문은 [닫힘 본문 복사]

여러 앱을 한 트리거에 고를 수 있지만, 앱 이름이 보이게 하려면 앱마다 매크로를 따로 만들어요.

3연결 테스트

PC 프로그램을 켠 채로 누르세요. PC 의 설정 칸이 3초 동안 초록으로 바뀌어요.

연결 정보가 없어요. PC 프로그램 › 설정 › 포커싱어플 › QR로 연결하기 에서 QR 을 다시 찍어 주세요.
