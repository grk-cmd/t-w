Together Working(이하 «앱»)은 책상 위에 사는 3D 캐릭터와 함께 집중하고, 친구와 같은 방에 모여 일하는 PC 프로그램입니다. 운영자는 「개인정보 보호법」 등 관련 법령을 지키며, 이 방침을 통해 앱이 어떤 정보를, 어떤 목적으로, 얼마나 오래 처리하는지 알려 드립니다.

한눈에 보기

  • 이름 · 전화번호 · 주소 같은 실명 정보는 수집하지 않습니다. 앱 안에서는 이용자가 정한 닉네임과 앱이 만든 사용자 코드를 사용합니다.
  • 이메일은 구글 계정으로 로그인한 경우에만 로그인 서비스(Google Firebase 인증)에 보관되며, 앱 데이터베이스에는 저장하지 않습니다.
  • 앱을 실행할 때 IP 주소를 알아볼 수 없는 값(해시)으로 변환하여 하루 방문자 수를 집계합니다. IP 주소 원문은 저장하지 않습니다.
  • 캐릭터 · 닉네임 · 마이홈 글처럼 다른 이용자에게 보이도록 만든 정보는 다른 이용자도 볼 수 있습니다(4항 참고).

IP 주소의 처리 방식

  • 앱은 실행 직후 서버 함수를 한 번 호출합니다. 이때 앱이 보내는 정보는 앱 버전뿐입니다.
  • 서버는 접속한 IP 주소를 운영자만 아는 비밀값과 해당 날짜를 섞어 단방향 해시(HMAC-SHA256)로 변환하고, 그중 16자만 저장합니다.
  • IP 주소 원문은 데이터베이스와 서버 기록(로그) 어디에도 저장하지 않습니다.
  • 날짜가 바뀌면 같은 IP 라도 전혀 다른 값이 되므로, 서로 다른 날의 기록을 같은 사람으로 연결할 수 없습니다.
  • 로그인하지 않은 이용자도 집계되지만, 해시값만으로는 이용자를 식별할 수 없습니다.

※ Google 서버를 거치는 과정에서 Google 이 자체 정책에 따라 접속 기록을 처리할 수 있습니다(6항 참고).

3처리 목적

  • 서비스 제공: 캐릭터 · 꾸미기 · 집중 기록 저장, 여러 PC 에서 같은 계정 이용, 방 · 채팅 · 친구 · 스티커사진 등 함께 쓰는 기능
  • 계정 보호: 로그인 확인, 같은 계정이 다른 PC 에서 실행되었을 때 알림
  • 신고 처리 및 운영: 부적절한 캐릭터 · 닉네임 · 자리비움 이미지 신고 확인과 조치, 라이선스 발급 · 확인
  • 서비스 통계: 일간 · 주간 · 월간 이용자 수와 방문 수를 집계하여 서비스 개선에 활용하며, 광고 제휴처에 제공할 수치(예: IP 기준 하루 방문자 수)를 산출합니다. 제휴처에는 합계 수치만 제공하며, 개별 사용자 코드나 해시값은 제공하지 않습니다.

앱은 광고를 위해 이용자를 추적하지 않습니다. 앱 안의 광고 배너는 누르면 기본 브라우저로 해당 주소를 여는 기능만 합니다.

4다른 이용자에게 공개되는 정보

여러 사람이 함께 쓰는 앱의 특성상 일부 정보는 다른 이용자도 볼 수 있도록 저장됩니다. 정보를 올리기 전에 참고해 주시기 바랍니다.

  • 사용자 코드를 아는 사람: 닉네임 · 레벨, 캐릭터 · 꾸미기, 자리비움 이미지, 마이홈(자기소개 · 글 · 프로필 그림), 방명록, 일정 · D-day, 플레이리스트, 공개로 설정한 책갈피, 친구 목록, 접속 여부, 받은 선물
  • 같은 방에 있는 사람: 방 안의 캐릭터 · 상태 · 말풍선 및 해당 방의 채팅 기록(방 코드를 아는 사람은 기록을 읽을 수 있습니다)
  • 모든 이용자: 집중 시간 순위표(상위 100명), 최근 공개된 플레이리스트 목록(닉네임 포함), 열려 있는 방 개수
  • 운영자만: 신고 내용, 라이선스 신청 목록, 계정 백업, 접속 지표

※ 비밀번호, 구글 이메일, IP 해시, 신고 내용은 다른 이용자에게 공개되지 않습니다.

7이용자 PC 에만 저장되는 정보

아래 정보는 서버로 전송하지 않고 이용자 PC 의 앱 데이터 폴더(앱 저장소 · 설정 파일)에만 저장합니다. 앱은 웹 쿠키로 이용자를 추적하지 않습니다.

  • 사용자 코드, 화면 위치 · 크기, 음량, 표시 설정, 채팅 읽음 표시, 캐시(카탈로그 · 공지 등)
  • 키보드 · 마우스 입력 여부와 현재 사용 중인 프로그램 이름 — 캐릭터 반응, 펜 앱 · 집중 앱 감지에만 사용하며 입력 내용이나 프로그램 이름은 서버로 전송하지 않습니다.
  • «진단 기록» 파일 — 문제가 생겼을 때 이용자가 직접 열어 전달할 수 있으며, 자동으로 전송하지 않습니다.
  • 스티커사진 · 채팅 내보내기 파일 — 이용자가 저장을 선택한 경우에만 만들어집니다.

앱을 삭제하면서 앱 데이터 폴더를 지우면 위 정보도 함께 삭제됩니다.

8이용자의 권리와 행사 방법

이용자는 언제든지 자신의 개인정보에 대해 열람 · 정정 · 삭제 · 처리 정지를 요구할 수 있습니다.

  • 앱에서 직접: 닉네임 · 캐릭터 · 마이홈 · 일정 · 플레이리스트 · 이모티콘은 앱에서 바로 수정하거나 삭제할 수 있습니다. 방장은 방의 대화 기록을 삭제할 수 있습니다.
  • 계정 전체 삭제: 현재 앱 안에는 «계정 삭제» 기능이 없습니다. 아래 연락처로 사용자 코드(또는 친구 코드)와 함께 요청하시면 확인 후 서버의 데이터와 로그인 계정을 삭제합니다. 요청을 받은 날부터 10일 이내에 처리합니다.
  • 연락처: gorokeeeee@naver.com

※ 접속 지표의 IP 해시는 누구의 정보인지 알 수 없으므로 특정 이용자의 것만 골라 삭제할 수 없습니다.

9안전성 확보 조치

  • 데이터베이스 보안 규칙으로 이용자의 데이터는 본인의 로그인 계정만 수정할 수 있도록 제한합니다. 다만 가입(로그인 연결)하지 않은 사용자 코드는 보호 수준이 낮으므로 가입을 권장합니다.
  • 비밀번호는 로그인 서비스(Google Firebase)가 보관하며, 앱 데이터베이스에는 저장하지 않습니다.
  • 서버와의 통신은 암호화(HTTPS)됩니다.
  • 운영자 화면은 지정된 관리자 계정만 접근할 수 있으며, 운영자 작업은 기록으로 남습니다.
