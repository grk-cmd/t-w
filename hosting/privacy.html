IP 주소는 이렇게 다뤄요

  • 앱이 켜지고 조금 뒤 서버 함수를 한 번 불러요. 이때 앱이 보내는 것은 앱 버전뿐이에요.
  • 서버는 접속한 IP 주소를 운영자만 아는 비밀값과 그날 날짜를 섞어 한 방향 해시(HMAC-SHA256)로 바꾸고, 그중 16자만 남겨요.
  • IP 주소 원문은 데이터베이스에도, 서버 기록(로그)에도 남기지 않아요.
  • 날짜가 바뀌면 같은 IP 라도 전혀 다른 값이 돼요. 그래서 다른 날의 기록끼리 같은 사람인지 이어 볼 수 없어요 — 일부러 그렇게 만들었어요.
  • 로그인하지 않은 사람도 세어지지만, 해시값만으로는 누구인지 알 수 없어요.

※ Google 의 서버를 거치는 과정에서 Google 이 자체 정책에 따라 접속 기록을 다룰 수 있어요(6번).

3왜 쓰나요

  • 앱 기능 제공: 캐릭터 · 꾸미기 · 집중 기록 저장, 여러 PC 에서 같은 계정 이어 쓰기, 방 · 채팅 · 친구 · 스티커사진 같은 함께 쓰는 기능
  • 계정 지키기: 로그인 확인, 같은 계정이 다른 PC 에서 켜졌는지 알리기
  • 신고 처리 · 운영: 부적절한 캐릭터 · 닉네임 · 자리비움 이미지 신고 확인과 조치, 라이선스 발급 · 확인
  • 서비스 통계: 하루 · 주 · 월 사용자 수와 방문 수를 세어 서비스를 개선하고, 광고 제휴처에 낼 숫자(예: IP 기준 하루 방문자 수)를 만드는 데 써요. 제휴처에는 합계 숫자만 알려 주고, 개별 사용자 코드나 해시값은 넘기지 않아요.

앱은 광고를 위해 사용자를 추적하지 않아요. 앱 안의 광고 배너는 누르면 기본 브라우저로 그 주소를 여는 것뿐이에요.

7내 PC 에만 남는 것

아래 정보는 서버로 보내지 않고 내 PC 의 앱 데이터 폴더(앱 저장소 · 설정 파일)에만 둬요. 앱은 웹 쿠키로 사용자를 추적하지 않아요.

  • 사용자 코드, 화면 위치 · 크기, 음량, 표시 설정, 채팅 읽음 표시, 캐시(카탈로그 · 공지 등)
  • 키보드 · 마우스 움직임과 지금 쓰는 프로그램 이름 — 캐릭터 반응, 펜 앱 · 집중 앱 감지에만 쓰고 입력한 내용이나 프로그램 이름을 서버로 보내지 않아요.
  • «진단 기록» 파일 — 문제가 생겼을 때 사용자가 직접 열어 보내 줄 수 있어요. 자동으로 보내지 않아요.
  • 스티커사진 · 채팅 내보내기 파일 — 사용자가 저장을 누를 때만 만들어져요.

앱을 지우면서 앱 데이터 폴더를 지우면 이 정보도 사라져요.

9안전하게 지키는 방법

  • 데이터베이스 보안 규칙으로 내 데이터는 내 로그인 계정만 고칠 수 있게 막아요. 단, 가입(로그인 연결)하지 않은 사용자 코드는 이 보호가 약하니 가입해 두기를 권해요.
  • 비밀번호는 로그인 서비스(Google Firebase)가 보관하고, 앱 데이터베이스에는 적지 않아요.
  • 서버와의 통신은 암호화(HTTPS)돼요.
  • 운영자 화면은 지정된 관리자 계정만 들어갈 수 있고, 운영자 작업은 기록으로 남아요.
