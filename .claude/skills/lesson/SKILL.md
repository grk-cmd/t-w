# /lesson — 리뷰 교훈 더하기

1. 지적을 한 줄로 줄인다: **무엇을 보면 → 왜 문제 → 어떻게 찾나**(grep 할 이름 · 경로 · 모양). 사연 · 날짜는 빼고, 이름 붙은 사고면 이름만(예: «말랑이 사고»).
2. `.claude/review-lessons.md` 의 맞는 절(데이터 · Firebase / 설계 / 동작 · 범위 — 없으면 새 절)에 더한다. 같은 뜻의 줄이 있으면 새로 쓰지 말고 그 줄을 다듬는다.
3. 기계로 판정할 수 있는 것(특정 함수 호출 · 경로 모양)이면 `checks/sim-*` 검사로 옮기자고 사용자에게 한 줄 제안한다(바로 만들지 않는다).
4. 지금 작업 브랜치에 커밋한다: `chore(harness): 리뷰 교훈 — <한 줄>`. 작업과 섞이지 않게 커밋은 따로.
