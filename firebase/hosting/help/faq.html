[공통] 게임이나 영상이 버벅여요

⚙️ 설정 › 디스플레이 › 실행 화면 화질을 «가볍게» 로 바꿔 보세요. 그래도 버벅이면 «최저» 로 바꿔 주세요(그림자가 꺼지고 움직임이 조금 뚝뚝해져요). 화질을 바꾼 뒤 프로그램을 다시 켜면 다 적용돼요. 노트북이라면 그래픽 드라이버를 최신으로 업데이트하는 것도 도움이 돼요.

[공통] 포커스 시간이 안 쌓여요

⚙️ 설정 › 포커싱 탭에 작업 프로그램을 등록해야 시간이 쌓여요. 등록한 프로그램이 관리자 권한으로 켜져 있으면 투게더워킹도 관리자 권한으로 켜 주세요. 피규어 모드(⚙️ 설정 › 캐릭터)가 켜져 있으면 포커스 기록이 쌓이지 않아요.

[공통] 일부 게임에서 포커스 기록이 감지되지 않아요

파이널판타지14 처럼 관리자 권한으로 실행되는 게임은 투게더워킹도 관리자 권한으로 실행해야 감지돼요. 투게더워킹 아이콘을 우클릭해 «관리자 권한으로 실행» 을 눌러 주세요(관리자 권한으로 켜면 컴퓨터 켤 때 자동 실행은 Windows 가 막아요). 포커싱 탭에 등록이 안 되면 칸을 우클릭해 창 목록에서 직접 골라 주세요.

🔗 5-3. 포커싱 탭

[공통] 레벨이 안 올라요

피규어 모드(⚙️ 설정 › 캐릭터)가 켜져 있지 않은지 확인해 주세요. 피규어 모드에서는 포커스 기록이 쌓이지 않아서 레벨도 오르지 않아요. 꺼져 있는데도 안 오르면 포커싱 탭에 작업 프로그램이 등록돼 있는지 봐 주세요.

PC 의 투게더워킹이 꺼져 있으면 폰 연결도 함께 멈춰요 — PC 프로그램을 켠 채로 써 주세요. 그래도 «쉬는 중» 만 뜨면 ⚙️ 설정 › 포커싱 탭의 📱 태블릿·폰 [QR로 연결하기]로 다시 연결해 주세요. 아이폰 · 아이패드는 단축어 자동화에서 «즉시 실행» 이 켜져 있는지도 봐 주세요.

🔗 5-6. 라이선스로 쓸 수 있는 것

[mac] 맥에 설치하는 법

설치 파일(.dmg)을 열고 Together Working 을 응용 프로그램 폴더로 끌어다 놓아요. 그다음 응용 프로그램 폴더에서 Together Working 을 열어 주세요.

[mac] 맥에서 확인되지 않은 개발자라고 나와요

시스템 설정 › 개인정보 보호 및 보안 맨 아래에서 «Together Working» 옆 [그래도 열기]를 누르고, 다시 뜨는 창에서 [열기]를 눌러 주세요.

[mac] 맥에서 손상되었기 때문에 열 수 없다고 나와요

응용 프로그램 › 유틸리티 › 터미널을 열고 xattr -cr "/Applications/Together Working.app" 를 붙여 넣은 뒤 Enter 를 눌러 주세요. 그다음 다시 열면 돼요.

[mac] 맥에서 타이핑해도 캐릭터가 안 움직여요

시스템 설정 › 개인정보 보호 및 보안 › 입력 모니터링과 손쉬운 사용에서 Together Working 을 켜 주세요. 켜져 있어 보여도 [−]로 지운 뒤 [+]로 다시 추가하고, 앱을 완전히 종료했다가 다시 실행해 주세요.

🔗 5-3. 포커싱 탭 › «키보드 입력이 감지되지 않고 있어요» 창이 떴을 때

[공통] 키보드 입력이 감지되지 않고 있어요

다른 프로그램이 키 입력을 가로채거나(Windows), 키 입력을 볼 권한이 빠졌을 때(Mac) 뜨는 창이에요. 키보드 보안 프로그램(TouchEn nxKey · AhnLab Safe Transaction 등)을 잠시 꺼 보고, 작업 프로그램을 관리자 권한으로 켰다면 투게더워킹도 관리자 권한으로 켜 주세요. 맥은 입력 모니터링 · 손쉬운 사용 허용을 지웠다가 다시 추가해 주세요.

🔗 5-3. 포커싱 탭 › «키보드 입력이 감지되지 않고 있어요» 창이 떴을 때

찾는 내용이 없으면 위 검색창에 물어보거나 마이홈 › 버그제보에 남겨 주세요.
