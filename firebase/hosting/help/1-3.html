로그인 수단 관리 (구글 연결 · 비밀번호)

로그인 방법은 메인 화면 › 내 정보 › 계정에서 관리해요.

  • 구글 연결 — 구글 계정으로 로그인할 수 있어요. 정책상 비밀번호는 받지 않고, 연결한 이메일만 읽어요.
  • 비밀번호 만들기 — 구글로 가입했더라도 비밀번호를 만들어 두면 구글 없이 친구 코드 + 비밀번호로 로그인할 수 있어요.

▶ 다른 컴퓨터에서 쓰려면

  1. 지금 컴퓨터에서 구글을 연결하거나 비밀번호를 만들어 둡니다.
  2. 새 컴퓨터에 설치하고 처음 화면에서 [구글로 로그인] 또는 [친구 코드로 로그인]을 누릅니다.

프로필 · 친구 · 마이홈 · 라이선스, 그리고 캐릭터까지 계정에 저장돼 함께 따라와요.

비밀번호는 모두 암호화되어 저장됩니다.

구글 계정 바꾸기

연결한 구글 계정을 다른 구글로 바꿀 수 있어요. 친구 코드 · 친구 · 마이홈 · 라이선스는 그대로예요.

  1. 메인 화면 › 내 정보 › 계정 › 로그인 수단의 구글 줄 아래 [바꾸기]를 눌러요. 지금 연결된 구글 주소가 일부 가려져 보여요(예: mi***@gmail.com).
  2. 구글 창이 뜨면 지금 연결된 구글을 골라요 — 본인 확인이에요.
  3. 구글 창이 한 번 더 뜨면 새로 연결할 구글을 골라요.
  4. «구글 계정을 바꿀까요?» 창에서 [바꾸기]를 눌러요. [취소]를 누르면 아무것도 바뀌지 않아요.
비밀번호가 있는 계정만 바꿀 수 있어요 — 바꾸는 동안 로그인이 끊기지 않게 하려는 거예요. [바꾸기]가 흐리게 보이면 위의 비밀번호 만들기를 먼저 해 주세요.
바꾼 뒤에는 새 구글로 로그인해요. 예전 구글로는 더 이상 이 계정에 들어오지 않아요.
새로 고른 구글이 이미 다른 투게더워킹 계정에 쓰이고 있으면 바꾸지 않고 원래 구글 그대로 둬요.
