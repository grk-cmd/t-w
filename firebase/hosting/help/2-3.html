2-3. 캐릭터 복제 & 불러오기

캐릭터 복제하기

만든 캐릭터를 다른 사람에게 전달하고 싶을 때 쓰는 기능이에요.

메인 화면 캐릭터 칸 오른쪽 위 ⚙를 눌러 [복제 코드 만들기]를 골라 주세요.

  1. 비밀번호를 정해 입력하고 [코드 생성]을 눌러요.
  2. 만들어진 코드는 [📁 파일로 저장]을 눌러 파일(복제코드.txt)로 저장하는 걸 권해요.
  3. 저장한 파일과 비밀번호를 함께 상대에게 전달해요.
⚠️ 코드가 아주 길어요. [복사]해서 카톡 같은 채팅으로 보내면 코드가 잘려 불러오기가 되지 않을 수 있어요. 꼭 파일로 전달해 주세요.

복제한 코드 불러오기

  1. 메인 화면 빈 칸의 [＋ 캐릭터 만들기]를 눌러요.
  2. 캐릭터 선택하기 창에서 [+ 코드 입력하기 (복제 코드 · 커미션 코드)]를 눌러요.
  3. [📂 파일 불러오기]로 전달받은 파일을 넣고(또는 코드를 붙여 넣고) 비밀번호를 입력해요.
  4. [캐릭터 등록]을 누르면 빈 칸에 캐릭터가 들어와요.

내 정보에서 불러오기

메인 화면 › 내 정보 › 보관함 아래 [코드로 캐릭터 불러오기]로도 불러올 수 있어요. (예전 메인 화면의 [캐릭터 불러오기] 버튼이 이 자리로 옮겨 왔어요.) 캐릭터 칸이 모두 차 있으면 불러올 수 없으니 칸을 하나 비워 주세요.

💡 서버 용량 때문에 동물 캐릭터를 복제 코드로 받으면 그림 해상도가 조금 낮아져요. 사람 캐릭터와 커미션 캐릭터는 그대로예요. 동물 캐릭터는 레벨 50이 넘어야 불러올 수 있어요.
