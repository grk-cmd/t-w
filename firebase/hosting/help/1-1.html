1-1. 처음 실행 · 가입 · 로그인

처음 실행하기

프로그램을 처음 실행하면 아래 화면이 나옵니다.

▶ 신규 유저

발급받으신 초대 코드를 입력한 뒤 [입장하기]를 눌러주세요.

이어서 계정 만들기 창이 나옵니다. 둘 중 편한 방법으로 가입해 주세요.

  • [구글로 가입하기] — 구글 계정으로 바로 가입
  • 친구 코드 + 비밀번호 — 내 아이디(친구 코드)는 자동으로 정해지고 바뀌지 않아요. 비밀번호는 6자 이상

▶ 기존 유저

초대 코드 없이 바로 로그인하면 됩니다.

  • 구글로 가입했거나 구글을 연결해 두었다면 [구글로 로그인]
  • 비밀번호를 만들어 두었다면 친구 코드와 비밀번호를 입력하고 [친구 코드로 로그인]

다른 컴퓨터에서 쓰던 계정이어도 같아요. 로그인하면 캐릭터와 기록이 그대로 따라옵니다.
