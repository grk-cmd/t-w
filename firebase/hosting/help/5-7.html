5-7. 태블릿 · 폰 연결

아이패드 · 갤럭시 탭 같은 태블릿이나 폰에서 그림을 그릴 때도 캐릭터가 작업 중으로 반응하고 포커스 시간이 쌓이게 연결할 수 있어요.

폰의 자동화 앱이 «그림 앱이 열렸어요 · 닫혔어요» 신호를 PC 로 보내는 방식이에요. 그래서 PC 의 투게더워킹이 켜져 있을 때만 시간이 쌓여요. PC 를 끄면 폰 연결도 함께 멈춰요.

1. PC 에서 QR 열기

  1. ⚙️ 설정 › 포커싱 아래쪽 📱 태블릿·폰 칸에서 [QR로 연결하기]를 눌러요.
  2. 뜬 QR 을 폰 카메라로 찍으면 설정 안내 페이지가 열려요. 이 페이지에 내 연결 정보가 들어 있으니 다른 사람에게 보내지 마세요.

이미 연결했다면 버튼 이름이 [QR 다시 보기]로 바뀌어요. 폰을 바꿨거나 안내 페이지를 다시 열 때 써요.

2. 폰에 자동화 앱 받기

iPhone · iPad기본 앱 단축어를 써요. 지웠다면 App Store 에서 «단축어» 를 다시 받아요.
안드로이드갤럭시 · 갤럭시 탭 등 — Play 스토어에서 MacroDroid 를 받아요(무료로 충분해요).

3. 자동화 만들기

안내 페이지의 [주소 복사] · [키 복사]로 하나씩 복사해 붙여 넣어요. 그림 앱 이름(예: Procreate · 클립 스튜디오)은 PC 에 보이는 이름이에요.

  • iPhone · iPad — 앱 이름은 아래 4번의 JSON 필드 app 값으로 직접 적어요.
  • 안드로이드 — 안내 페이지의 앱 이름 칸에 적으면 [열림 본문 복사] · [닫힘 본문 복사]에 들어가요. 앱 이름을 바꾸면 다시 복사해 주세요.

iPhone · iPad (단축어)

  1. 단축어 › 자동화 › ＋ › 앱 그림 앱 고르기 → «열릴 때»만 체크 → 즉시 실행 · «실행 시 알림» 끄기
  2. 새로운 빈 자동화 동작 «URL 콘텐츠 가져오기» 추가
    URL[주소 복사] 한 것
    방법POST
  3. 같은 동작 › «표시» › «헤더» 헤더 추가 두 개
    «키» 칸«텍스트» 칸
    X-Mobile-Key[키 복사] 한 것
    Content-Typeapplication/json
    iOS 판에 따라 «키 · 텍스트» 가 «이름 · 값» 으로 보여요 — 왼쪽 칸이 이름, 오른쪽 칸이 값이에요.
  4. 같은 동작 › «요청 본문» › JSON «새로운 필드 추가» 두 개
    종류키값
    불리언on참
    텍스트app그림 앱 이름
    on 은 종류를 꼭 «불리언» 으로 골라요(«텍스트» 로 «참» · «true» 를 적지 않아요).
  5. 같은 방법으로 «닫힐 때» 자동화를 하나 더 이번엔 on 값만 거짓

앱마다 «열릴 때 · 닫힐 때» 두 개씩 만들어요. 헤더 값은 직접 치지 말고 [키 복사] 한 것을 붙여 넣어요.

예전(PUT) 방식으로 만들었다면

예전 방식(방법 PUT · «텍스트» 동작 · 요청 본문 «파일»)으로 만들었다면 방법을 POST 로 바꾸고, «텍스트» 동작을 지우고 위처럼 헤더 · «JSON» 으로 바꿔요. 방법이 PUT 이면 서버가 받지 않아요.

안드로이드 (MacroDroid)

  1. 매크로 추가(«새 매크로») › 트리거 › 애플리케이션 › 앱 실행/종료 실행됨 → 그림 앱 고르기
  2. 액션 › 연결(웹 접속) › HTTP 요청
    방법POST
    URL[주소 복사] 한 것
  3. 헤더
    이름값
    X-Mobile-Key[키 복사] 한 것
  4. 본문
    콘텐츠 유형application/json
    본문[열림 본문 복사] 한 것
  5. 새 매크로를 하나 더 트리거 종료됨 · 본문은 [닫힘 본문 복사]

⚠️ «열림» 과 «닫힘» 은 꼭 매크로를 따로 만들어요. 열림 매크로에는 실행됨 트리거와 열림 요청만, 닫힘 매크로에는 종료됨 트리거와 닫힘 요청만 둬요.

한 매크로에 같이 넣으면 왜 안 되나요?

한 매크로에 실행됨 · 종료됨 트리거와 열림 · 닫힘 HTTP 요청을 함께 넣으면, 트리거가 하나만 일어나도 그 매크로의 액션이 모두 실행돼요. 그러면 앱을 열 때도 닫을 때도 «열림» 과 «닫힘» 이 함께 가서 기록이 뒤죽박죽이 돼요.

예전(PUT) 방식으로 만들었다면

예전 안내대로 방법을 PUT 으로 만들었다면 POST 로 바꾸고 헤더 X-Mobile-Key 를 넣어요 — PUT 이면 서버가 받지 않아요.

MacroDroid 는 판에 따라 메뉴 이름이 조금 달라요 — 안내 페이지의 괄호 안이 한국어 화면의 이름이에요.

4. 연결 확인

PC 프로그램을 켠 채로 안내 페이지의 [신호 보내 보기]를 눌러요. PC 의 📱 태블릿·폰 칸이 3초 동안 초록으로 바뀌면 PC 연결은 된 거예요.

이 버튼은 PC 연결만 확인해요. 만든 자동화가 맞는지는 그림 앱을 직접 열어서 PC 칸이 «📱 (앱 이름) 사용 중» 으로 바뀌는지로 확인해요. 테스트는 초록인데 앱을 열면 «쉬는 중» 이면, 자동화가 신호를 안 보냈거나 모양이 틀린 거예요 — 3번을 다시 봐 주세요.

📱 태블릿·폰 칸에는 지금 상태가 보여요.

📱 (앱 이름) 사용 중초록폰에서 그림 앱을 쓰는 중이에요. 포커스 시간이 쌓이고 있어요.
연결됨 · 폰에서 쉬는 중노랑연결은 됐고, 지금은 그림 앱이 닫혀 있어요.
연결 안 됨회색아직 연결하지 않았거나 신호를 기다리는 중이에요. «폰에서 [신호 보내 보기]를 눌러 보세요» 가 보이면 4번부터 다시 해 주세요.
  • 그만 쓰려면 [연결 끊기]를 눌러요.
  • QR 창의 [키 새로 만들기]를 누르면 예전 폰 연결이 끊기고 폰에서 다시 설정해야 해요. 폰을 잃어버렸거나 남에게 줬을 때만 써 주세요(새 폰으로 옮길 땐 [QR 다시 보기]면 돼요).
  • 두 버튼 모두 실수로 눌리지 않게 한 번 더 눌러야 실행돼요.
폰에서 그린 시간은 포커스 시간 · 레벨에 쌓여요. 👑 달성표의 🎯 집중 시간에는 들어가지 않아요(PC 에서 고른 프로그램만 재요). 피규어 모드가 켜져 있으면 폰 시간도 쌓이지 않아요. «닫힐 때» 신호가 오지 않은 채 4시간이 지나면 «사용 중» 은 저절로 풀려요.

손으로 누르면 되는데 자동으로는 안 될 때

iPhone · iPad

  • 자동화 편집 화면에서 «즉시 실행»이 켜져 있는지 확인해요(iOS 16 이하는 «실행 전에 묻기»를 꺼요).
  • 단축어 안에는 «URL 콘텐츠 가져오기» 동작 하나만 둬요. «메뉴에서 선택» · «입력 요청» · «결과 보기»처럼 눌러야 하는 동작이 있으면 자동으로는 멈춰요.
  • «닫힐 때» 자동화가 «열릴 때»와 같은 앱인지 확인해요. 다른 앱을 고르면 열자마자 «닫힘»이 가서 꺼진 것처럼 보여요.

안드로이드

  • 처음 고를 때 권한을 달라는 창이 뜨면 허용해요.
  • 신호가 가끔 안 가면 설정 › 애플리케이션 › MacroDroid › 배터리 에서 «제한 없음»으로 바꿔요.
  • 여러 앱을 한 트리거에 고를 수 있지만, PC 에 앱 이름이 보이게 하려면 앱마다 매크로를 따로 만들어요.
