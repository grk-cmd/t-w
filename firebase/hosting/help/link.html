1받기

기본 앱 단축어를 써요. 지웠다면 App Store 에서 «단축어» 를 다시 받아요.

갤럭시 탭 같은 안드로이드 태블릿 · 폰은 Play 스토어에서 MacroDroid 를 받아요(무료로 충분해요).

2자동화 만들기

⚠️ 예전 안내대로 만든 자동화는 지금 신호가 가지 않아요. 예전 안내의 방법 PUT 을 지금 서버가 받지 않아요. 방법을 POST 로 바꾸고 헤더 X-Mobile-Key 를 넣어 아래처럼 다시 만들어요. iPhone · iPad 단축어는 «텍스트» 동작을 지우고 본문을 «JSON» 으로 바꿔요.

그림 앱 이름은 아래 4번의 app 값으로 적어요. PC 에 이 이름이 보여요.

그림 앱 이름을 적으면 아래 복사 버튼에 들어가요. PC 에 이 이름이 보여요.

  1. 단축어 › 자동화 › ＋ › 앱 그림 앱 고르기 → «열릴 때»만 체크 → 즉시 실행 · «실행 시 알림» 끄기
  2. 새로운 빈 자동화 동작 «URL 콘텐츠 가져오기» 추가
    URL[주소 복사] 한 것
    방법POST
  3. 같은 동작 › «표시» › «헤더» 헤더 추가 두 개
    «키» 칸«텍스트» 칸
    X-Mobile-Key[키 복사] 한 것
    Content-Typeapplication/json
    iOS 판에 따라 «키 · 텍스트» 가 «이름 · 값» 으로 보여요 — 왼쪽 칸이 이름(X-Mobile-Key), 오른쪽 칸이 값이에요.
  4. 같은 동작 › «요청 본문» › JSON «새로운 필드 추가» 두 개
    종류키값
    불리언on참
    텍스트app그림 앱 이름
    on 은 종류를 꼭 «불리언» 으로 골라요(«텍스트» 로 «참» · «true» 를 적지 않아요).
  5. 같은 방법으로 «닫힐 때» 자동화를 하나 더 이번엔 on 값만 거짓

앱마다 «열릴 때 · 닫힐 때» 두 개씩 만들어요. 헤더 값은 직접 치지 말고 [키 복사] 한 것을 붙여 넣어요.

손으로 누르면 되는데 자동으로는 안 될 때 · 자동화 편집 화면에서 «즉시 실행»이 켜져 있는지 확인해요(iOS 16 이하는 «실행 전에 묻기»를 꺼요).
· 단축어 안에는 «URL 콘텐츠 가져오기» 동작 하나만 둬요. «메뉴에서 선택» · «입력 요청» · «결과 보기»처럼 눌러야 하는 동작이 있으면 자동으로는 멈춰요.
· «닫힐 때» 자동화가 «열릴 때»와 같은 앱인지 확인해요. 다른 앱을 고르면 열자마자 «닫힘»이 가서 꺼진 것처럼 보여요.
  1. 매크로 추가(«새 매크로» · 매크로 탭 오른쪽 아래 «+») › 트리거(빨간 «발동» 탭) › 애플리케이션 › 앱 실행/종료 실행됨(«앱 실행») → 그림 앱 고르기
  2. 액션(«동작») › 연결(또는 «웹 접속») › HTTP 요청
    방법POST(«설정» 탭 › 요청 종류)
    URL[주소 복사] 한 것
  3. 헤더(«Header» · «헤더 추가»)
    이름값
    X-Mobile-Key[키 복사] 한 것
  4. 본문(«Body 내용» 탭)
    콘텐츠 유형(«컨텐츠 타입»)application/json
    본문[열림 본문 복사] 한 것
  5. 새 매크로를 하나 더 트리거 종료됨 · 본문은 [닫힘 본문 복사]
⚠️ «열림» 과 «닫힘» 은 꼭 매크로를 따로 만들어요 한 매크로에 실행됨 · 종료됨 트리거와 열림 · 닫힘 HTTP 요청을 함께 넣으면, 트리거가 하나만 일어나도 그 매크로의 액션(«동작»)이 모두 실행돼요. 그러면 앱을 열 때도 닫을 때도 «열림» 과 «닫힘» 이 함께 가서 기록이 뒤죽박죽이 돼요. 열림 매크로에는 실행됨 트리거와 열림 요청만, 닫힘 매크로에는 종료됨 트리거와 닫힘 요청만 둬요.
잘 안 될 때 · 메뉴 이름이 다를 때

MacroDroid 판에 따라 메뉴 이름이 달라요 — 괄호 안이 한국어 화면의 이름이에요. 처음 고를 때 권한을 달라는 창이 뜨면 허용해요.

여러 앱을 한 트리거에 고를 수 있지만, 앱 이름이 보이게 하려면 앱마다 매크로를 따로 만들어요.

신호가 가끔 안 가면 설정 › 애플리케이션 › MacroDroid › 배터리 에서 «제한 없음»으로 바꿔요.

매크로 편집 화면의 «테스트 실행»(또는 ▶)으로 HTTP 요청을 바로 보내 볼 수 있어요 — 그때 PC 설정 칸에 앱 이름이 뜨면 매크로 설정은 맞고, 앱을 열어도 안 뜨면 트리거(«실행됨») · 권한 · 배터리 쪽이에요. 열림 매크로를 시험했으면 닫힘 매크로도 한 번 실행해 «사용 중» 을 꺼 주세요.

3연결 테스트

PC 프로그램을 켠 채로 누르세요. PC 의 설정 칸이 3초 동안 초록으로 바뀌어요.

이 버튼은 PC 연결만 확인해요. 만든 자동화가 맞는지는 그림 앱을 직접 열어서 PC 설정 칸이 «📱 (앱 이름) 사용 중» 으로 바뀌는지로 확인해요. 테스트는 초록인데 앱을 열면 «쉬는 중» 이면, 자동화가 신호를 안 보냈거나 모양이 틀린 거예요 — 위 2번을 다시 봐 주세요.

연결 정보가 없어요. PC 프로그램 › 설정 › 포커싱 › QR로 연결하기 에서 QR 을 다시 찍어 주세요.
